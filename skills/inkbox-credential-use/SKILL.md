---
name: inkbox-credential-use
description: Use identity-scoped vault access when the user asks to use a saved credential.
---

List metadata first. Plaintext credential tools are disabled unless enabled individually by their exact name in tools.enable. Group or all does not unlock them. Never ask the user to paste a vault key in chat; they can set INKBOX_PI_VAULT_KEY locally. Use the least sensitive tool needed and avoid echoing credentials or saving them in messages or notes.
